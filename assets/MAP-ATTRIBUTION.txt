SemiSocket proposed markets map — source and reproduction notes

Map geometry: us-atlas 3.0.1, states-10m.json (2017 U.S. Census cartographic
state boundaries, simplified to 1:10m). Includes all 50 states and Washington,
D.C. Alaska and Hawaii appear as insets, not at their continental positions.
Sources:
https://github.com/topojson/us-atlas
https://cdn.jsdelivr.net/npm/us-atlas@3.0.1/states-10m.json
https://www2.census.gov/geo/tiger/GENZ2017/shp/cb_2017_us_state_500k.zip

Projection: d3-geo 3.1.1 geoAlbersUsa, fitted to viewBox 0 0 1000 630 with
35 units of padding. Alaska is scaled to 0.35 times its true relative area.
https://d3js.org/d3-geo/conic#geoAlbersUsa
Topology conversion: topojson-client 3.1.0.
https://github.com/topojson/topojson-client

City positions: 2024 U.S. Census national place Gazetteer INTPTLAT / INTPTLONG.
These are representative points for cities, not confirmed charger locations.
https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2024_Gazetteer/2024_Gaz_place_national.zip

Reproduce assets:
  npm ci
  node project-points.mjs
Optional input: node project-points.mjs path/to/cities.json
  JSON array entries: { name, state, latitude, longitude }
Outputs: us-states.svg and projected-cities.json.
For an HTML pin overlay, use xPercent/yPercent as percent left/top inside a
container with aspect-ratio 1000 / 630. Match the SVG image's full viewBox.
